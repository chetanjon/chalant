# Chalant 1.21.0

Names for both ears.

## Add a name

Under Learn my names there is now a box. Type a name the way it should land,
and Chalant spells it that way from then on: the first ear as it writes, the
second ear as it listens. The names you type sit in the same list as the ones
Chalant learned from your fixes, with the same x to forget them.

## Names from Contacts

If you let Chalant read Contacts, the names in it help too. A button under
that list asks macOS for you; Chalant never asks on its own. It reads names
only, on this Mac, and keeps them nowhere: nothing is written down and nothing
leaves the machine.

## The second ear reads your names before it listens

With Better hearing on, the stronger ear now sees a short list of your names
before it hears each sentence: the ones you typed, the ones it learned, and
whichever contacts sound like a word the first ear just produced. Measured on
the founder's own voice, on sentences full of names, its errors fell by two
thirds. A long list would make it slower and worse, so the list is short and
chosen for each sentence.
