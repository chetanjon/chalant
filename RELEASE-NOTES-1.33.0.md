# Chalant 1.33.0

The update row answers when you look.

## Settings now checks when you do

Chalant checks for new versions once a day, but a release published
after that daily look stayed invisible until the next one. Now opening
the General page is itself the ask: Chalant quietly checks right then,
and a small line always tells the truth, which version you run and
when it last looked. When something new exists, the install button is
there as before. Nothing installs without you asking, same as always.
