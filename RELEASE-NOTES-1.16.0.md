# Chalant 1.16.0

It remembers your names after one fix.

## Fix a name once

Dictate, and if Chalant gets a name wrong, fix it by typing over the word.
That is the whole ceremony. From then on it knows the name: the next time
the same mishearing comes out, it is corrected before it lands, and the name
joins the vocabulary Chalant listens for.

Before, it needed to see the very same mistake, fixed the very same way,
twice. Names are misheard differently every time, so that almost never
happened, and it looked like it was not learning at all. It was not.

## The one place it still waits

If the mishearing happened to be an ordinary English word, say "challenge"
for Chalant, the exact swap waits for you to fix it a second time. That is
deliberate: a rewrite learned from one slip would otherwise start changing
every ordinary "challenge" you ever say. The name itself is learned at once
either way.

## It watches the way you actually work

You dictate in bursts, across apps. Chalant now keeps watching a message
box for your fix even if you dictate somewhere else in the meantime, for
forty-five seconds rather than twenty. And if you fix two or three words in
one sentence, it learns all of them.

Everything it has learned is listed under Settings, Dictation, Learn my
names, where any pair can be removed.
