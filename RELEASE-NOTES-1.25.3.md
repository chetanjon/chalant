# Chalant 1.25.3

Clip rows keep and copy, they don't jump.

## A quieter clipboard

Each copied item now offers exactly the actions a clip is for: pin it,
copy it back, keep it on the Shelf, AirDrop the ones that are files or
screenshots, remove it. The button that jumped you out of the pane to
ask about the text is gone from clipboard rows, so nothing there ever
switches surfaces on you.
